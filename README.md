# DSA 405: Data Wrangling and Web Scraping — Fall 2026

NC State Data Science and AI Academy · Section 001 · Fridays, Aug 21 – Nov 20

> **Assume it's broken. Prove it isn't.**

This repository holds the student materials for DSA 405: assignments, labs, project
handouts, rubrics, and every dataset we use. Materials are posted here as the course
progresses; Moodle links point directly to the files in this repo, so this is the
authoritative copy of everything.

## How to use this repo

- **Notebooks (`.ipynb`)** open directly in Google Colab: from the notebook page on
  GitHub, copy the URL into [Colab](https://colab.research.google.com) via
  *File → Open notebook → GitHub*, or use the Moodle link, which does this for you.
  Save your own copy to Drive before working — edits in the preview are not saved.
- **Datasets** load over HTTPS in every lab and notebook; you never need to download
  them by hand. See [datasets/README.md](datasets/README.md) before you trust any of
  them — every file is broken in ways you will have to find, and all of it is
  simulated (no real restaurant, school, permit, or person).
- **Handouts and rubrics (`.md`)** render right on GitHub.
